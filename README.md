# Deu Verde

Site do projeto Deu Verde (Desafio Green Tech). Versão para GitHub Pages: o CSS e o JavaScript estão dentro do `index.html`, então só são necessários estes arquivos:

```
index.html
assets/img/   (logo e ícones)
```

## Publicar no GitHub Pages

1. Envie `index.html` e a pasta `assets` para a **raiz** do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
3. Aguarde 1 a 2 minutos e abra `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

Atenção: o GitHub diferencia maiúsculas de minúsculas. Mantenha `assets/img` em minúsculas e os nomes dos arquivos exatamente como estão.

Nomes da equipe e da instituição: edite o rodapé do `index.html` (há um comentário no lugar).
